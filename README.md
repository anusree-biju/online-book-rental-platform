# online-book-rental-platform
A mini project for book rental system using HTML, CSS, PHP, MySQL.
  
A complete mini-project that allows users to post books for rent, rent books posted by others, manage orders, give feedback, and make payments.  
Includes a full **Admin Panel** for managing users, books, and approvals.

---

## Features

### User Module
- User Registration & Login  
- Profile Management  
- Post a Book for Rent  
- Edit or Delete Own Books  
- Browse & Search Books  
- Add Books to Cart  
- Rent Books  
- Track Orders / Rental Status  
- Give Feedback with Ratings  
- View Payments

---

### Admin Module
- Admin Login  
- Manage Users (Delete / View details)  
- Manage Books (Accept / Reject / Delete)  
- View All Rental Orders  
- View Payments  
- Manage Feedbacks  
- Dashboard with Counts

---

### Payment Module
- User can make payments for rentals  
- Payment details stored in database  
- Admin can view all payments

---

### Rental Management
- Rent book for specific period  
- Track rental status  
- Admin approves book postings  
- User can track rented/returned status
